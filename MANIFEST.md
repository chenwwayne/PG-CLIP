# Release manifest

This repository contains the paper-specific AA-CLIP, Generic Prompts, APSF,
and KAN-Residual implementation for the AMOLED Active/Cell and MVTec AD
carpet/grid protocols.

Included: source code, split and conversion utilities, tests, environment
specifications, documentation, and citation/licensing metadata.

Excluded: datasets, pretrained weights, learned checkpoints, logs, metrics,
visualisations, internal experiment archives, and unrelated ablations.

The OpenAI CLIP checkpoint must be obtained separately as described in the
README. No local workstation, private repository, or server path is required.
